📱 Telefonda ilova sifatida o'rnatish

Panelni telefonning bosh ekraniga qo'shsangiz — alohida ilova kabi (manzil satrisiz, to'liq ekranda) ochiladi.

  • iPhone (Safari): pastdagi «Ulashish» tugmasi → «Bosh ekranga qo'shish».
  • Android (Chrome): yuqoridagi ⋮ menyu → «Ilovani o'rnatish» yoki «Bosh ekranga qo'shish».

Jonli kamera (skaner) va o'rnatish uchun sayt HTTPS (domen) bilan ochilgan bo'lishi kerak. Pastki menyuda: Bosh · O'quvchilar · Ball · Skaner · Menyu.

{% endmacro %} {% call q("🔒 «Natijalar qulflangan» deyapti — ball kiritish qanday ochiladi?") %}

Qulf ikki xil: fan qulfi (bitta fan) va tur qulfi (butun tur, barcha fanlar). Qaysi biri yoqilgani «Ball kiritish» sahifasi tepasida yozilgan va o'sha yerda «🔓 Ochish» tugmasi bor.

  1. Bosh sahifa → «Natijalar kiritilishi» jadvali → kerakli fan qatoridagi 🔓 Ochish tugmasi.
  2. Yoki «Ball kiritish» sahifasida tepadagi sariq quti ichidagi 🔓 «…» fanini ochish / turini ochish.
  3. Butun tur qulflangan bo'lsa (Bosh sahifa pastida yoki «O'rinlar va mukofotlar»da) — 🔓 Turni ochish.

Ochgach hakamlar yana ball kiritishi va titullarni skaner qilishi mumkin. Yakunlagach yana 🔒 Qulflash ni bosing. Har qulflash/ochish «Jurnal»da yoziladi.

{% endcall %} {% call q("Qulfni nima uchun ishlataman?") %}

Natijalar yakuniy bo'lgach, hakam tasodifan ball o'zgartirib yubormasligi va reytingdagi o'rinlar turg'un bo'lishi uchun. Sertifikatlarni yuborishdan oldin turni qulflash tavsiya etiladi.

{% endcall %} {% call q("Ballni xato kiritibman. Qanday tuzataman?") %}

Fan qulflanmagan bo'lsa — «Ball kiritish»da shu o'quvchini toping va to'g'ri qiymatni yozib «Saqlash»ni bosing. Qulflangan bo'lsa avval oching (yuqoriga qarang). Titul orqali kiritilgan bo'lsa: «📝 Titul va skaner → Ishlar» dan o'sha ishni oching va javoblarni tahrirlang.

{% endcall %} {% call q("Titul boshqa o'quvchiga berilib qolsa nima bo'ladi?") %}

Tizim uch qavat himoyalaydi: titullar xona va o'rin tartibida chop etiladi; o'quvchi o'z ID sini belgilaydi; skaner QR dagi ID bilan solishtiradi. Mos kelmasa natija yozilmaydi va ish 🔎 Tekshirish kerak ga tushadi — rasmni ko'rib, to'g'ri o'quvchiga yozasiz.

{% endcall %} {% call q("Telefonda skaner kamerani ochmayapti") %}

1) Sayt https:// bilan ochilganini tekshiring (domen kerak). 2) Brauzer kameraga ruxsat so'raganda «Ruxsat berish»ni bosing (sozlamalar → sayt ruxsatlari). 3) Hozircha domen bo'lmasa — «📸 Suratga olish» tugmasi bilan har titulni alohida suratga oling.

{% endcall %} {% call q("Skaner «aniq o'qilmadi» deyapti") %}

Titulni yorug' joyda, ramka ichiga to'liq (4 ta burchak ko'rinadigan) va qimirlatmasdan tuting. Doirachalar yengil bo'yalgan bo'lsa — «Admin tekshirsin» tugmasi bilan yuboring, admin rasmni ko'rib hal qiladi.

{% endcall %} {% call q("Kalitni (to'g'ri javoblarni) olimpiadadan keyin kiritsam bo'ladimi?") %}

Ha. Skanerlangan ishlar saqlanadi; kalitni «📝 Titul va skaner → Fanlar va kalitlar»da kiritib «Saqlash va hisoblash»ni bossangiz hammasi avtomatik ballanadi. Kalit o'zgarsa — qayta hisoblanadi.

{% endcall %} {% call q("Hakamga o'quvchi ismi ko'rinmasin / ko'rinsin") %}

{% endcall %} {% call q("Hakam parolini unutdi") %}
